# Boleh Beli Ke?

A free, single-file web app that helps young Malaysians check whether they can afford a buy-now-pay-later (BNPL) purchase before they tap "Buy".

- Enter income and must-pay bills
- Add every instalment (SPayLater, Atome, Grab, etc.)
- See a verdict: safe, careful or danger
- Check a new purchase before buying

No sign-up. No bank login. Numbers stay on the user's own phone (browser storage).

Languages: Bahasa Malaysia (default) and English.

Prototype. Guidance only, not financial advice. Personal project, not a CGC product.

## Run
Open `index.html` in any browser. No build step.
